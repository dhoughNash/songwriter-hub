The MLC Bulk Registration Export

Exports a .xlsx file pre-formatted to match The MLC's official bulk upload template (MLCBulkWork_V1_2).

Upload at portal.themlc.com → Works → Bulk Upload. Mark songs as submitted in the Song Vault after uploading.

SESAC Bulk Registration Export

Exports a .xlsx file pre-formatted to match SESAC's official bulk upload template. Each writer on a song gets their own row.

Upload the downloaded file at sesac.com → My Account → Song Registration → Bulk Upload. Mark songs as submitted in the Song Vault after uploading.

MusicMark Bulk Registration Export (BMI / ASCAP / SOCAN)

Exports a .xlsx file formatted for MusicMark's bulk upload, accepted by BMI, ASCAP, and SOCAN.

Upload at musicmark.com. Works for BMI, ASCAP, and SOCAN registrations.

How to get a free API Key (5 min)
  1. Go to console.cloud.google.com and sign in with your Google account
  2. Click Select a project → New Project → name it anything (e.g. "Songwriter Hub") → Create
  3. In the search bar type Google Sheets API → click it → click Enable
  4. Go to APIs & Services → Credentials → + Create Credentials → API Key
  5. Copy the key and paste it above. That's it — it's free and never expires.
  6. Important: Make sure your Google Sheet is set to "Anyone with the link can view" (Share → change access)
